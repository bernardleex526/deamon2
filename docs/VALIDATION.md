## 2026-09-18 验收记录

### 软件测试

- 单元测试：`test_motion_guard` + `test_nav_sender` + `test_follow_runtime`
  共 **131 个用例全部通过，无 skip**（清洁环境，仅 source ROS Foxy，
  `PYTHONPATH` 包含工程根，`python3 -B`）。
- 隔离 ROS 集成测试：`test_follow_runtime_ros` 共 **11 个用例全部通过，
  exit 0**。运行于 `ROS_DOMAIN_ID=47` + 批准的 UDP-only Fast-DDS 配置，
  使用真实 DDS 发布/订阅但与现场域隔离；**无真实遥测网络通信（不触
  AOS 遥测服务端）且无实际 HTTP 请求（fetch 注入替代）**——两者是相互
  独立的验证点，不混为一谈。
- 测试纪律：严禁在 `ROS_DOMAIN_ID=0` 上运行隔离集成测试；
  `test_preview_ros` 占用 8080/8890 端口，不能在现场三个服务运行时执行，
  也不放入默认 all-discover 运行。

### 首次实机短窗口运动（现场人工分段授权，用户全程见证）

> 硬件上只实际验证过 **0.5 s 与 3 s** 两个运动窗口；`--motion-seconds ≤ 10`
> 是软件允许的单会话上限（单元/域 47 测试验证），不是硬件验收结论。

| 项目 | 结果摘要 |
|---|---|
| 0.5 s 运动窗口 | NAV 非零指令 7 帧 + 收尾零速 1 帧；前进速度约 0.250–0.261 m/s；进程 exit 0；用户现场见证机器狗前进而后停止 |
| 3 s 运动窗口 | NAV 非零指令 56 帧 + 收尾零速 1 帧；速度上限 0.3 m/s、末段约 0.27 m/s；目标距离由 2.223 m 收敛至 1.741 m；全程 42 帧 scan 判定 clear；deadline 到期 / disarm ACK 正常、exit 0；用户现场见证椅子移动、机器狗跟随并停止 |

### 验收边界（必须与结论一并阅读）

- 以上速度数值来自软件日志计数，**未经物理速度仪器测量**。
- 本次验收**不覆盖**：急停响应、断网行为、长时间连续运动、复杂避障、
  双雷达失效、几何参数标定校验。
- live 会话每次均需现场人工分段授权（三旗 + 显式 arm）；不存在"一键长时
  跟随"或自动 live 循环的已验收路径。**真实长时间连续跟随当前不支持**，
  需要另行设计看门狗、急停链路与几何标定并重新验收。
- exit 0 只表示进程有界运行正常结束，不等于机械已停止（零速补发不保证
  物理停止）。
